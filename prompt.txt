Напиши телеграм-бот, в котором будет следующий функционал:
1) Приветствие будет типа "Загрузите PDF файл который нужно перевести".
2) В бот можно загрузить PDF файл
3) После загрузки файла будет запускаться мой python скрипт с названием gpttranslate.py и загруженный файл будет передаватся в скрипт как аргумент.
4) Результатом работы моего скрипта будет созданный новый файл с названием как у исходного, но в конце названия перед форматом файла .pdf -  добавлсяется "_en".
5) Новый файл отправляется в чат пользователю залившему исходный файл.
